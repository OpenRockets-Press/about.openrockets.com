# OpenRockets® Open-Source

OpenRockets Press was built for young creators, and the licenses below were written to answer a question that most existing open source licenses never had to ask. What happens when the author of a piece of software or code is not old enough to sign a contract. Three licenses answer that question in three different ways, and a fourth option, Creative Commons Attribution 4.0, is offered alongside them for creators who would rather use a license the rest of the world already recognizes.

## OpenRockets Beaver

![OpenRockets Beaver](https://press.openrockets.com/brand/licences/beaver,png.png)

Beaver protects software and code published by creators under the age of eighteen. It is a semi open source license, which means the door is only fully open to other minors. Another young creator anywhere in the world is free to copy a Beaver licensed project, share it, or build a derivative version of it, as long as they cite the original OpenRockets Press page it came from. A fifteen year old who publishes a small mobile game under Beaver, for example, can expect a classmate in another country to fork that game for a school assignment, add new levels to it, and publish the result, provided the classmate links back to the original submission.

Adults and the general public are a different story. They may view a Beaver licensed project freely, but they cannot use it, meaning copy it, run it inside a product, or build on top of it, without asking first. The request goes through a form at openrockets.com/licenses/request, and OpenRockets Press reviews it on the original creator's behalf. This is the part of Beaver that took the most thought to design. A minor should not be expected to personally negotiate with a company or a stranger who wants to use their work, so OpenRockets Press acts as the party in the middle, deciding whether the requested use lines up with a fair use policy before granting or denying it.

Two things happen depending on how a use is detected. If OpenRockets Press can determine on its own that a use of the code clearly falls under fair use, that use is approved automatically, without a person on the team needing to step in at all. If instead someone submits a formal request to use a Beaver licensed project in a way that is not automatically covered, a member of the OpenRockets team reviews that request by hand, records the decision alongside the project it concerns, and updates the relevant pages once a decision has been made.

Minors who want to reuse another minor's Beaver licensed work do not need to file any request at all. Citation is enough. Leaving out that citation is treated as a violation of the license, in the same way that leaving out a citation on any other copyrighted work would be.

OpenRockets is currently in the process of formally registering Beaver as a recognized license.

## OpenRockets Kangaroo

![OpenRockets Kangaroo](https://press.openrockets.com/brand/licences/kangarooo.png)

Kangaroo is the fully open option. Where Beaver keeps a gate between minors and adults, Kangaroo removes that gate entirely for anyone who wants to use the underlying code. Software and code published under Kangaroo can be copied, used commercially, used for nonprofit work, turned into a derivative project, and shared again, by anyone, with no request required.

The one condition Kangaroo insists on is citation. Anyone using a Kangaroo licensed project must credit the original minor by name and link back to the original OpenRockets Press submission as the source. A startup that wants to build a product around a sixteen year old's open sourced API wrapper is free to do exactly that under Kangaroo, provided the startup's documentation or credits page names the original author and points back to where the code was first published.

## OpenRockets Hummingbird

![OpenRockets Hummingbird](https://press.openrockets.com/brand/licences/hummingbird.png)

Hummingbird sits between the other two. It is open to both minors and adults, and there is no gate to request access through. Anyone can copy a Hummingbird licensed project and use it exactly as published. The one thing Hummingbird does not allow, for anyone, minor or adult, is derivative work. It is a non derivative license, so a project may be reused and redistributed as a whole, but it may not be modified and republished as something new.

In practice this means a teacher who wants to hand a Hummingbird licensed lesson plan to a class of students can copy and distribute it freely, as long as the source link, or the source link together with the original creator's name, is displayed prominently alongside it. What the teacher cannot do is rewrite half of the lesson plan and publish that rewritten version as their own project.

## Creative Commons Attribution 4.0

OpenRockets Press also supports Creative Commons Attribution 4.0, the license maintained by Creative Commons in Mountain View, California. It is the option for creators who would rather use a license the rest of the world already recognizes, rather than one written specifically for minors. Creative Commons Attribution 4.0 lets anyone distribute, remix, adapt, and build on a published work, in any medium and any format, as long as proper credit is given back to the original creator. The full terms are available at https://creativecommons.org/licenses/by/4.0/
